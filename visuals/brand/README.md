# Marca KONAET

O cubo roxo é o arquivo original de `7dsolv/konaet-cover`, indicado pelo proprietário. A origem e o SHA-256 estão em [source.json](source.json).

O renderer usa essa imagem na capa e na animação, e copia seus bytes sem alterações para o ícone da App. O nome público é **KONAET**. A letra K geométrica da apresentação anterior foi substituída.

O caminho do pacote continua `7dsolv/konaet-bot` para preservar as integrações existentes. O nome de apresentação e o slug de um repositório são campos diferentes. A miniatura da Action no Marketplace usa os ícones predefinidos aceitos pelo GitHub; o cubo aparece na apresentação e pode ser usado como avatar da GitHub App.
